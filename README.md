# Application science

Application mobile (Android / iOS) qui recense en français les avancées scientifiques du moment,
trouvées, résumées et classées automatiquement par un agent IA.

- `agent/` — agent de collecte (Python), lancé depuis l'onglet **Actions → Agent de collecte → Run workflow**
- `database/` — schéma de la base Supabase
- `app/` — application Flutter (à venir)
- `JOURNAL.md` — historique des décisions et des étapes
